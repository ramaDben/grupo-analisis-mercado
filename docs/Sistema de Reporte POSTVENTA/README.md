# Sistema de Reporte POSTVENTA

Exportación del proyecto de Claude Design de GI donde se está diseñando el reporte
de post-venta: los dos documentos del canvas (`Sistema Editorial` y
`Editor Documentos`), sus scripts de apoyo y los archivos subidos, entre ellos el
Informe Semanal del 6 de agosto de 2026 en `.docx` y `.pdf`.

Se versiona **como referencia de diseño**, no como código del repo. Nada de acá se
ejecuta ni se importa: los `.js` son los del runtime del canvas y vienen dentro de
la descarga.

La fuente viva sigue siendo el canvas. Si el diseño cambia allá, esta carpeta queda
atrás hasta que alguien vuelva a exportarla, así que conviene mirar la fecha de los
archivos antes de tomarla como vigente.

Distinto del comando `/postventa` del repo, que genera el parte diario para el
equipo interno: esto es el reporte editorial y su maqueta.
